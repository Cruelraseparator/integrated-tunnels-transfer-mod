# Integrated Tunnels — Item/Fluid Transfer Mod

[![Download Latest](https://img.shields.io/github/v/release/Cruelraseparator/integrated-tunnels-transfer-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Cruelraseparator/integrated-tunnels-transfer-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Transfer items, fluids, and energy between inventories using Integrated Dynamics variable logic.

![Integrated Tunnels — Item/Fluid Transfer Mod Preview](https://cdn.modrinth.com/data/Etqy1Omb/e12f45ef60f20726d4a54c1caa5ea7d51388a349_96.webp)

## Features

- Item Tunnel transfers items with Integrated Dynamics filters
- Fluid Tunnel for logic-driven liquid transfer
- Energy Tunnel for conditional RF/FE transfer
- Supports any inventory accessible by Dynamics
- Enables complex conditional automation pipelines

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
